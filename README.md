# 🏋️ IronLog

**Seu treino. Sua evolução.**

Aplicativo de registro de treinos e dieta para praticantes de musculação e exercícios físicos. Registre seus treinos, acompanhe sua evolução e controle sua alimentação — tudo em um só lugar.

> Desenvolvido como Trabalho de Conclusão de Curso (TCC) em Engenharia de Software.  

</div>

---

## ✨ Funcionalidades

- 💪 **Registro de Treinos** — Crie e registre suas sessões de treino com exercícios, séries, repetições e cargas
- 📈 **Acompanhamento de Progresso** — Visualize sua evolução ao longo do tempo com histórico detalhado
- 🥗 **Controle de Dieta** *(em desenvolvimento)* — Monitore sua alimentação e macronutrientes diários
- 🔐 **Autenticação** — Login com e-mail/senha ou conta Google
- 📱 **Design Responsivo** — Interface adaptada para mobile e desktop

---

## 🎨 Design

O IronLog adota um tema **dark agressivo** com **laranja vibrante** como cor de destaque, transmitindo a energia e intensidade do ambiente de musculação.

- **Paleta principal:** `#0d0d0f` (fundo) · `#ff5a28` (destaque) · `#f0ede8` (texto)
- **Tipografia:** Bebas Neue (títulos) + DM Sans (corpo)

## 🚀 Como Rodar

### Pré-requisitos

- [Node.js](https://nodejs.org) 18+
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/ironlog.git

# Entre na pasta do projeto
cd ironlog

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse `http://localhost:5173` no seu navegador.

## 🎓 Sobre o TCC

Este projeto foi desenvolvido como Trabalho de Conclusão de Curso do curso de **Engenharia de Software**.

**Objetivo:** Desenvolver uma aplicação web/mobile que auxilie praticantes de musculação no registro e acompanhamento de treinos e dieta, oferecendo uma alternativa nacional e acessível aos aplicativos estrangeiros do segmento.
